# Props générés — 12 septembre 2026

Outil utilisé : génération d’images intégrée (pas de CLI, pas de clé API). Originaux copiés dans `public/assets/props`. La transparence générée est conservée ; le moteur recadre les marges à l’affichage à partir du canal alpha.

Sélection finale : `grass-v1.png`, `flowers-v1.png`, `stones-v1.png`, `house-v1.png`. Deux tentatives de retouche pour supprimer les halos de l’herbe et des pierres ont produit un damier opaque : elles sont rejetées et déplacées dans `.local/rejected-props`, hors des assets consommés. Le contrôle du canal alpha indique respectivement 94 %, 90 %, 94 % et 79 % de pixels complètement transparents dans les images retenues.

Prompt de retouche rejeté : « Edit this game prop sprite. Preserve the exact subject, silhouette, placement and color family. REMOVE ALL the blurry glow, fog, halo, bloom and soft translucent haze surrounding it. Make it a clean low-resolution pixel-art sprite with only hard stepped pixel edges and solid flat colors. Outside the solid object must be completely transparent alpha=0. Inside it must be opaque. No cast shadow, no background, no gradient, no ambient lighting. Do not draw a checkerboard. The final asset should work as a tiny 24-pixel-wide prop in a game. Keep the whole object and transparent margins. »

Front view with a tiny amount of top visible, consistent 2D game prop. Must still read perfectly after nearest-neighbor downscaling to 32 pixels wide. It should look like an actual low-resolution 24x16 sprite enlarged with nearest-neighbor, extremely simple silhouette, compact and low.
